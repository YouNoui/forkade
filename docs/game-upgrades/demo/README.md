# Demolition Chain: reactor demolition yard

Cached shaped masonry, cross-braced steel and warning-symbol gas tiles replace flat blocks. A three-layer forge backdrop, procedural music and shared chain hit feedback make each blast readable. Destroying 12 masonry blocks at a site awards +150 once; every reward field and cosmetic debris RNG is rewind-safe. Quiet solvability checks never award bonuses. Old scores are retained; cap 2,500,000 and badge tiers 1,300 / 3,500 / 8,000.

Validation: 30-second simulation, seed replay, three-second rewind, explicit bonus/RNG restoration, actual charge/detonate taps on Chromium Android 390, WebKit iPhone 390 and desktop 1280. Existing API and Assist parity checks pass. Local headless CPU frame cost 0.54ms (baseline render 1.16ms; different scripted workload, not a physical-phone FPS measurement). Source 14,909 bytes after, 13,192 bytes before. No physical haptics or mid-range Android GPU claim.

Before/after MP4 is outside git at shared process/forkade-games-before-after/demo.mp4. Screenshots here show real local gameplay. Landscape game retains its rotate hint; no portrait layout claim. No new connectors/scopes, login, player data or external submission.
