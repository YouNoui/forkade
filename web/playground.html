⇧ Submit to FORKADE
Your game is a class that extends Forkade.GameBase with reset(), step(dt), render(ctx), snapshot() and restore(s). Rewind (hold R) works for free as long as snapshot() returns everything that changes. Helpers: NE.glowRect, NE.glowCircle, NE.drawEcho, NE.text, NE.banner, this.particles, this.shake, NE.sfx, this.input. Submitting opens GitHub: drop in your downloaded file and it becomes a pull request (guide). Read any game in web/games for more.
Press ▶ Run to play your game. Keys: arrows/WASD, SPACE, hold R to rewind, P pause.
🔒 Your code stays in this browser (saved on this device only). Nothing is uploaded unless you submit it yourself on GitHub.
