# FORKADE

Open-source neon arcade. Play it, rewind it, fork it.

The browser edition has **thirteen games**, including ECHO 3D, RAMPAGE 3D and three 2D destruction games: Tower Wrecker, Glass City and Demolition Chain. RAMPAGE turns ECHO into a giant city-stomper with a timer, chunks, joystick controls and rewind.

**Rewards:** every game pays out *cores* (finish rounds, clear levels, beat your best), plus bronze/silver/gold badges per game, a rank and a daily streak. Spend cores on ECHO skins in the Locker. All of it stays on the device.

**Global rankings (opt-in):** after a round, players can post their score with a nickname, no sign-up. Daily, weekly and all-time top 50 per game. Enable ranked runs before playing to receive a temporary single-use token; suspicious jumps go to owner review. Backend: `api/leaderboard.js` (Vercel function) + Upstash Redis. Posted scores include a random player ID for ranking/deletion; temporary run tokens contain no personal details.

**Stats and legal:** explicitly opt-in, anonymous, cookie-free visit/play counts (`api/stats.js`, owner view at `/stats.html`). Terms, Privacy, Community rules and Delete my data pages are generated by `tools/make_legal.py`.

**Make your own:** open `playground.html` (live at https://playforkade.com/playground.html), edit the starter game, press Run, then submit it. See [CONTRIBUTING.md](CONTRIBUTING.md). Serve `web/` with any static host (no build step), or run `python -m http.server --directory web 8080`. Open http://localhost:8080.

Fork: https://github.com/YouNoui/forkade. MIT licensed; bundled third-party notices are retained.

**Daily Challenge:** one seeded game per Singapore day, the same level/layout on every device. Finish for local cores; claim a top-ten bonus the next day after posting. Daily boards expire after three days.

**Share and settings:** every game has a `/game-id` link and a generated social preview. Share scores after a round. The gear opens local mute/volume, reduced motion, colour-blind shapes, and separate opt-ins for ranked runs and anonymous counts. Casual play sends neither. No cookies or third-party trackers.

**Phones:** Sky Hop, Sky Striker and Pulse Breaker have tall portrait layouts. Other 2D games recommend landscape. Safari unlocks audio on a user gesture; add the arcade using Share → Add to Home Screen. Both 3D games work offline and use thumb-stick controls.

## Design

FORKADE follows the IAMYNOUI UX playbook with colour trio **B**:

| Role | Token | Value | Used for |
|---|---|---|---|
| Ink / base | `--base` (+ `--panel`, `--panel2`, `--line`, `--text`, `--muted`) | `#0b0a10` | page, panels, text |
| Brand | `--brand` | cyan `#22e1ff` | title, links, badges, progress, selected tabs |
| Pop | `--pop` with `--pop-ink` text | yellow `#ffd84d` | only the one main action per screen |
| Status | `--ok`, `--danger` | `#4ade80`, `#ff5a6e` | success / destructive only |

Games keep their own colours (card `--c`, skins, canvas palettes, 3D worlds); everything around them uses the trio.
Tokens live in `web/index.html` `:root`; never hard-code a hex in UI.

Buttons use one set of classes: `.btn` (secondary), `.btn-pop` (main), `.btn-dark`, `.btn-link`, `.btn-danger`
(always confirmed with `UI.confirm`). Every button is at least 44px tall and has all states via `UI.busy(btn, "Posting…")`,
`UI.done(btn, "Posted")` and `UI.reset(btn)`. Success moments use `UI.burst(el)` (once per screen). On phones every pop-up is
a bottom sheet (swipe down, tap outside, ✕ or Esc). Motion is off under `prefers-reduced-motion` and the Reduce motion setting.

## Regenerate and test

Install Pillow using `pip install -r tools/requirements.txt`. Run `python tools/build_rampage.py`, `python tools/make_legal.py`, `python tools/build_previews.py`, then `python web/build_dist.py`. Vercel serves the committed `web/` output with no build step. For local routing/API fixtures, use `node tests/server.cjs` (in-memory data only).

Run `npm ci`, `npx playwright install chromium webkit`, `npm test`, and `npm run test:browser`. Set `WEBKIT=1` to test WebKit. See [validation evidence](docs/upgrade-validation.md), including the Windows WebKit audio limitation.

To regenerate only the single-file download: `python -X utf8 web/build_dist.py`. Bump the cache version in `web/sw.js` when changing web assets.

## Original Python edition


A collection of **6 small Python games** that share one hero, one neon look,
and one unusual twist. No sign-ups, no accounts, no internet — download, run,
play. Fully open source (MIT) and built to be extended.

> **The unique idea:** every game stars the same little neon droid, **ECHO**,
> and every game lets you **rewind time**. Mess up a jump, get swarmed, clip a
> rock — hold **R** (or **Shift**) and the game runs *backwards* on your own
> energy meter so you can retry the moment. One mechanic, six genres.

This answers all four of the things you asked to tie them together:

| You asked for… | How FORKADE does it |
|---|---|
| One shared world / hero | Every game stars **ECHO**, drawn by one function |
| A shared engine others can extend | One `neonkit.py` toolkit under all six games |
| One unusual mechanic across genres | **Rewind time** works in all six |
| Procedural neon theme + juice | Shared starfield, glow, particles, screen-shake |

---

## The six games

1. **Sky Hop** — a bouncy platformer climb (the Roblox-obby vibe)
2. **Neon Swarm** — a top-down survival shooter (the "shoot the zombies" one)
3. **Sky Striker** — a vertical airplane shmup (the "airplane that shoots" one)
4. **Pulse Breaker** — a neon brick-breaker
5. **Echo Trail** — a glowing neon snake
6. **Driftstorm** — spin-and-blast space rocks

## Run it

You need Python 3.9+ and pygame.

```bash
pip install pygame
python launcher.py
```

Pick a game with the arrow keys (or the mouse) and press **ENTER**. Each game
opens in its own window; press **ESC** to return to the menu.

You can also run any game on its own:

```bash
python games/game2_swarm.py
```

### Controls (shared across all games)

- Move / aim: **WASD** or **Arrow keys** (+ **mouse** in the shooters)
- Shoot / jump / launch: **SPACE** (or **mouse click**)
- **Rewind time: hold R or SHIFT**
- Pause: **P**   ·   Back to menu: **ESC**

## How it's built (and how to extend it)

```
Forkade/
├── launcher.py          # the arcade menu
├── engine/
│   └── neonkit.py       # shared toolkit: palette, glow, ECHO, particles,
│                        # screen-shake, starfield, HUD, and the Rewind twist
├── games/
│   ├── game1_skyhop.py
│   ├── game2_swarm.py
│   ├── game3_striker.py
│   ├── game4_breaker.py
│   ├── game5_trail.py
│   └── game6_drift.py
├── README.md
├── LICENSE              # MIT
└── requirements.txt
```

Each game subclasses `neonkit.GameBase` and only has to write four methods:

```python
import neonkit as nk

class MyGame(nk.GameBase):
    title = "MY GAME"

    def step(self, dt, keys, events):   # your game logic for one frame
        ...
    def render(self, surf):             # draw your frame
        ...
    def snapshot(self):                 # return a copy of your state (for rewind)
        return (...)
    def restore(self, snap):            # put that state back (for rewind)
        ...
```

`GameBase` gives you the window, the 60fps loop, the gradient background, the
starfield, particles, screen-shake, pause, and the rewind overlay for free —
and because every game reports a `snapshot`, **the rewind mechanic works in
any new game automatically**.

### Add a 7th game

1. Copy any file in `games/` as a starting point.
2. Change the class, `title`, and the four methods.
3. Add one line to the `GAMES` list in `launcher.py`.

That's it — it inherits the shared look and the rewind twist.
