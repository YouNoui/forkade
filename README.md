# FORKADE

Open-source neon arcade. Play it, rewind it, fork it.

**ECHO RUMBLE 2 beta** leads the arcade: Singapore-date seeded runs across seven toy stages and three bosses, up to three replayed allies, rewind, eight chaos events and 48 free avatar choices. Explicit Post shares a server-validated anonymous input replay for today’s Ghost Rumble. Forge builds preset-only practice runs, with optional short-code publishing and real weekly play counts.

The browser edition also has **thirteen classic games**, including ECHO 3D, RAMPAGE 3D and three 2D destruction games: Tower Wrecker, Glass City and Demolition Chain. RAMPAGE turns ECHO into a giant city-stomper with a timer, chunks, joystick controls and rewind.

**Classic polish:** all thirteen games have refreshed procedural worlds, feedback, music and rewind-safe powers or goals. See `docs/game-upgrades/` for measured checks and screenshots. Before/after clips are saved in the shared process folder; headless timings are not physical-phone FPS claims.

**Rewards:** every classic game pays out *cores* (finish rounds, clear levels, beat your best), plus bronze/silver/gold badges per game, a rank and a daily streak. Spend cores on ECHO skins in the Locker. All of it stays on the device.

**Global rankings (opt-in):** after a round, players can post their score with a nickname, no sign-up. Daily, weekly and all-time top 50 per game. Enable ranked runs before playing to receive a temporary single-use token; suspicious jumps go to owner review. Backend: `api/leaderboard.js` (Vercel function) + Upstash Redis. Posted scores include a random player ID for ranking/deletion; temporary run tokens contain no personal details.

**Stats and legal:** default-on anonymous, cookie-free visit/play counts with a Settings opt-out (`api/stats.js`, owner view at `/admin`). Terms, Privacy, Community rules and Delete my data pages are generated by `tools/make_legal.py`.

**Make your own:** open `playground.html` (live at https://playforkade.com/playground.html), edit the starter game, press Run, then submit it. See [CONTRIBUTING.md](CONTRIBUTING.md). Serve `web/` with any static host (no build step), or run `python -m http.server --directory web 8080`. Open http://localhost:8080.

Fork: https://github.com/YouNoui/forkade. MIT licensed; bundled third-party notices are retained.

**Daily Challenge:** one seeded game per Singapore day, the same level/layout on every device. Finish for local cores; claim a top-ten bonus the next day after posting. Daily boards expire after three days.

**Share and settings:** every game has a `/game-id` link and a generated social preview. Share scores after a round. The gear opens local mute/volume, reduced motion, colour-blind shapes, and an opt-in for ranked runs and an opt-out for anonymous counts. Rumble starts anonymous round tokens; only Post uploads the replay. Usage counts respect Settings, DNT and GPC. No cookies or third-party trackers.

**Phones:** Sky Hop, Neon Swarm, Sky Striker, Pulse Breaker, Core Match, ECHO Trail and Prism Stacks have tall portrait layouts. Other 2D games recommend landscape. Safari unlocks audio on a user gesture; add the arcade using Share → Add to Home Screen. All three 3D games work offline and use thumb-stick controls.

## Design

FORKADE follows the IAMYNOUI UX playbook with colour trio **B**:

| Role | Token | Value | Used for |
|---|---|---|---|
| Ink / base | `--base` (+ `--panel`, `--panel2`, `--line`, `--text`, `--muted`) | `#0b0a10` | page, panels, text |
| Brand | `--brand` | cyan `#22e1ff` | title, links, badges, progress, selected tabs |
| Pop | `--pop` with `--pop-ink` text | yellow `#ffd84d` | only the one main action per screen |
| Status | `--ok`, `--danger` | `#4ade80`, `#ff5a6e` | success / destructive only |

Games keep their own colours (card `--c`, skins, canvas palettes, 3D worlds); everything around them uses the trio.
Tokens live in `web/index.html` `:root`; never hard-code a hex in UI.

Buttons use one set of classes: `.btn` (secondary), `.btn-pop` (main), `.btn-dark`, `.btn-link`, `.btn-danger`
(always confirmed with `UI.confirm`). Every button is at least 44px tall and has all states via `UI.busy(btn, "Posting…")`,
`UI.done(btn, "Posted")` and `UI.reset(btn)`. Success moments use `UI.burst(el)` (once per screen). On phones every pop-up is
a bottom sheet (swipe down, tap outside, ✕ or Esc). Motion is off under `prefers-reduced-motion` and the Reduce motion setting.

## Original Python edition


A collection of **6 small Python games** that share one hero, one neon look,
and one unusual twist. No sign-ups, no accounts, no internet — download, run,
play. Fully open source (MIT) and built to be extended.

> **The unique idea:** every game stars the same little neon droid, **ECHO**,
> and every game lets you **rewind time**. Mess up a jump, get swarmed, clip a
> rock — hold **R** (or **Shift**) and the game runs *backwards* on your own
> energy meter so you can retry the moment. One mechanic, six genres.

This answers all four of the things you asked to tie them together:

| You asked for… | How FORKADE does it |
|---|---|
| One shared world / hero | Every game stars **ECHO**, drawn by one function |
| A shared engine others can extend | One `neonkit.py` toolkit under all six games |
| One unusual mechanic across genres | **Rewind time** works in all six |
| Procedural neon theme + juice | Shared starfield, glow, particles, screen-shake |

## Run it

You need Python 3.9+ and pygame.

```bash
pip install pygame
python launcher.py
```

Pick a game with the arrow keys (or the mouse) and press **ENTER**. Each game
opens in its own window; press **ESC** to return to the menu.

You can also run any game on its own:

```bash
python games/game2_swarm.py
```

### Controls (shared across all games)

- Move / aim: **WASD** or **Arrow keys** (+ **mouse** in the shooters)
- Shoot / jump / launch: **SPACE** (or **mouse click**)
- **Rewind time: hold R or SHIFT**
- Pause: **P**   ·   Back to menu: **ESC**

## How it's built (and how to extend it)

```
Forkade/
├── launcher.py          # the arcade menu
├── engine/
│   └── neonkit.py       # shared toolkit: palette, glow, ECHO, particles,
│                        # screen-shake, starfield, HUD, and the Rewind twist
├── games/
│   ├── game1_skyhop.py
│   ├── game2_swarm.py
│   ├── game3_striker.py
│   ├── game4_breaker.py
│   ├── game5_trail.py
│   └── game6_drift.py
├── README.md
├── LICENSE              # MIT
└── requirements.txt
```

Each game subclasses `neonkit.GameBase` and only has to write four methods:

```python
import neonkit as nk

class MyGame(nk.GameBase):
    title = "MY GAME"

    def step(self, dt, keys, events):   # your game logic for one frame
        ...
    def render(self, surf):             # draw your frame
        ...
    def snapshot(self):                 # return a copy of your state (for rewind)
        return (...)
    def restore(self, snap):            # put that state back (for rewind)
        ...
```

`GameBase` gives you the window, the 60fps loop, the gradient background, the
starfield, particles, screen-shake, pause, and the rewind overlay for free —
and because every game reports a `snapshot`, **the rewind mechanic works in
any new game automatically**.

### Add a 7th game

1. Copy any file in `games/` as a starting point.
2. Change the class, `title`, and the four methods.
3. Add one line to the `GAMES` list in `launcher.py`.

That's it — it inherits the shared look and the rewind twist.

## Owner admin

`/admin` (with `/stats.html` redirecting) is unlocked with the `STATS_KEY` environment variable in Vercel (Production and Preview, marked Sensitive, so
Vercel won't show it again). To change it: Vercel → forkade → Settings → Environment Variables → STATS_KEY → Edit, save,
then redeploy (any merge to `main` does it). Never commit the key or paste it into issues or chats.

## Local rewards and honest rules

Free gifts use stored deadlines, three welcome rewards and disclosed 80/15/5 regular chances. The optional prize machine has six exclusive skins, fixed collection-based chances, duplicate refunds and a guaranteed second re-roll. Assist is offered after three losses and enabled only by choice; it never affects Daily, rankings or badges. Singapore-day round cores pay full for 40 rounds, half through 80, then a quarter. Weekly social proof is server-calculated and hidden below 20 players. Anonymous A/B groups change only the Start here card; opt-out, DNT and GPC disable counting.

Fair play reads rules directly from shared constants. Everything earned stays on this device. No ads, payments, accounts or third-party trackers. Additional tests: `node tests/growth.cjs`, `node tests/assist.cjs`, `node tests/bonus.cjs`, `node tests/experiment.cjs`, `node tests/fair.cjs`.


Owner tabs: Stats, Moderation and Promo codes. Codes grant local cores, skins and gifted Rumble parts; they never alter scores, badges or earned rank. All Rumble parts remain free. The code field lives in Settings; shared code links open it filled in. Stable server-only PROMO_SALT protects per-code device hashes; rate hashes expire in 60 seconds. Code usage is atomic in Redis. Test with node tests/promo-browser.cjs and npm test, using isolated preview keys only.

## ECHO RUMBLE 2

Four free animated CC0 heroes, hit-charged supers, two gadgets per stage, dashes,
three seeded upgrade picks, Normal/Hard/Insane and a weekly Singapore Nightmare.
Echo Road and hero mastery stay local; fixed unlocks (including Nova) are shown
from shared constants on Fair play. Promo gifts can grant the same cosmetics.
Friend ghost links share only genuine explicitly posted runs, expiring after
three days. Live co-op rooms are **not enabled** pending verified free relay access.

Art: KayKit Adventurers and Prototype Bits, CC0; see THIRD_PARTY_NOTICES and
licenses/. `node tools/build_rumble_assets.mjs` rebuilds compressed GLBs (optional
`RUMBLE_SOURCE_DIR` reuses original downloads); `node tools/render_rumble_portraits.cjs`
renders the small selection portraits. Then run the existing Python generators.
Runtime assets are same-origin and lazy; the downloadable single file embeds them.

V3 input replays bind hero, difficulty, gadget and weekly mode to the run token;
legacy v2 replays remain readable. Local unlocks are editable and are not an
anti-cheat guarantee. New tests: rumble-v2.test.cjs, rumble-v2-online.test.cjs and
rumble-v2-browser.cjs. Browser emulation does not prove physical Android 60 FPS.
