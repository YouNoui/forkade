# FORKADE

Open-source neon arcade. Play it, rewind it, fork it.

Play at **https://playforkade.com**. ECHO RUMBLE 2 beta leads thirteen classic games:
eleven Canvas games plus ECHO 3D and RAMPAGE 3D. All games support rewind; the
single-file download works offline. The Playground lets contributors build games
with the same engine. MIT licensed, with credited CC0 art and retained third-party licences.

## ECHO RUMBLE 2

Four free animated heroes (Volt, Lumen, Flick and Mason), hit-charged supers, two
gadgets per stage, dash and three seeded upgrade picks. Seven stage types, three
original bosses with three phases, local replay allies and eight chaos events.
Normal, Hard, unlocked Insane and Singapore-week Nightmare use separate boards.
Assist is available on unranked Normal. The original 48 avatar choices remain optional.

Echo Road, hero mastery and the collection stay on the device. Every unlock has a
fixed requirement shown from shared constants on Fair play. Only explicit Post
uploads a bounded, server-validated input replay for three days. Genuine friend
ghost links expire or disappear with the posted replay. Legacy v2 replays remain
readable alongside the current v3 verifier. Forge uses closed preset vocabulary;
practice earns no Road XP or cores, and optional published codes expire after 90 days.

## Design

Read the shared IAMYNOUI playbook linked in AGENTS.md before UI changes.
The shell uses dark `--base #0b0a10`, cyan `--brand #22e1ff`, and yellow
`--pop #ffd84d` with dark ink for the single main action. Games retain their own
palettes. System monospace fonts, 44px controls, local settings and reduced motion
are preserved. Seven 2D games have portrait layouts; other 2D games recommend landscape.

## Fair play and privacy

`/fair.html` reads reward requirements, chances and limits from the same constants
as gameplay. Cores, badges, gifts, streaks, Assist and bonus tiers stay local.
There are no accounts, payments, cookies, ads or third-party trackers.
Anonymous first-party visit/play counts default on, with a Settings opt-out and
DNT/GPC support. Ranked classic runs are opt-in; Rumble starts anonymous two-hour
run tokens. Posting is always explicit and shares the disclosed score/nickname,
random player ID and, for Rumble, the validated replay. These checks are not cheat-proof.
Legal pages are generated by `tools/make_legal.py`; update copy/version there.

## Owner stats/admin

`/admin` has Stats, Moderation and Promo tabs; `/stats.html` redirects there.
The existing server-only `STATS_KEY` is sent as a header, held only in sessionStorage
and cleared by Lock. Never print, commit or paste it into an issue. Vercel Functions
use Upstash Redis; preview keys are branch-prefixed. Never test writes against production.

## Promo codes

Owner codes grant local cores or closed-catalog cosmetics, without changing earned
rank, scores or badges. Explicit Settings/link redemption, atomic usage limits,
per-code salted device hashes and an idempotent local receipt ledger prevent
accidental repeat grants. Keep `PROMO_SALT` stable and server-only. Original Rumble
parts stay free. Requirements and limits are described by the same shared catalog.

## Run and rebuild

For routing and in-memory API fixtures: `node tests/server.cjs`.
For a static-only server: `python -m http.server --directory web 8080`.
Vercel serves committed `web/` with no hosted build step.

```sh
npm ci
pip install -r tools/requirements.txt
python tools/build_echo3d.py
python tools/build_rampage.py
python tools/build_rumble.py
python tools/make_legal.py
python tools/build_previews.py
python web/build_dist.py
```

Bump `web/sw.js` CACHE for web changes. Generated social pages, icons, OG images,
compressed models and the offline download are production assets and remain in git.
The canonical offline bundle is `web/download/forkade.html`; the old duplicate
`dist/forkade.html` is no longer tracked. The small homepage gameplay loop/poster are served production media, not test recordings.

CC0 assets: `node tools/build_rumble_assets.mjs` (optional `RUMBLE_SOURCE_DIR` reuses
downloads), then `node tools/render_rumble_portraits.cjs` and the Python generators.
Only runtime-selected animation clips are retained. All eight npm packages are
build/test dependencies; production has no npm installation. See THIRD_PARTY_NOTICES.

## How to run tests

```sh
npx playwright install chromium webkit
npm test
npm run test:browser
# PowerShell: $env:WEBKIT='1'; npm run test:browser
WEBKIT=1 npm run test:browser
npm run test:offline
npm run test:suite
npm run test:coverage
```

`test:suite` runs the complete local browser/assertion suite, both browser matrices,
offline tests and release checks. `tests/server.cjs`, `redis.cjs`, `artifacts.cjs` and
`coverage.cjs` are helpers. `test:preview` requires an explicit isolated branch URL
in `FORKADE_PREVIEW_URL`; it never accepts production. Coverage writes JS/CSS evidence
outside the checkout; unexecuted code alone is not proof that code is dead.

`FORKADE_ARTIFACTS` overrides the output root. Locally it defaults to
`~/Desktop/shared process/echo-rumble/archive/test-output`; CI uses its temporary folder.
Historical screenshots are archived outside git; written release evidence remains
in `docs/` and is marked historical. See [cleanup evidence](docs/cleanup-2026-11-24.md).
Recording tools are `tools/record_game.cjs` and `tools/record_rumble.cjs`.
Headless timings do not prove physical Android 60 FPS, iPhone speaker output or OS install UI.

## Original Python edition

The original six pygame games remain supported source: `pip install -r requirements.txt`,
then `python launcher.py`. `engine/neonkit.py` supplies the shared engine; `games/`
contains the six games. Keep this edition when cleaning the browser build.

## Community games

Build original games in the [Playground](https://playforkade.com/playground.html),
then follow [CONTRIBUTING.md](CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
Use the GitHub bug, idea or game-submission templates. Contributions must preserve
local-first play, opt-in posting and MIT-compatible licensing.
