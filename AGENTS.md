# FORKADE — agent instructions

- Static arcade: deploy `web/`, with no hosted build step. Preserve all thirteen games (eleven 2D, ECHO 3D and RAMPAGE 3D) and rewind controls.
- Games must be original takes on a genre: no copied names, art, piece sets or layouts of existing games (e.g. no Tetris-style 7-tetromino 10x20 well).
- `web/playground.html` lets anyone build a game in the browser; keep its starter game running whenever engine.js changes.
- Rewards (cores, badges, skins, streak) live in `Forkade.rewards` in engine.js and stay in localStorage only. New games get them automatically; add score tiers to `GOALS` (or `meta.goals`).
- Privacy announcements must be true: play/progress/settings are local-first; no cookies, ads or third-party trackers. Rankings and anonymous counts default off. Explain exactly what each optional feature sends before opt-in. Never claim that posted rankings data is not collected.
- Rankings: `api/leaderboard.js` + Upstash Redis (env `KV_REST_API_URL`/`KV_REST_API_TOKEN`). Ranked-run opt-in starts random two-hour tokens; Post explicitly shares nickname, game, score and random player ID. Add `CAPS` and `lib/runs.js` rate bounds for new games. Tokens are single-use; suspicious score jumps await owner review. These checks are not cheat-proof.
- Daily: `web/daily.js` is shared with the server. Singapore midnight, six seeded games, device-independent daily layouts. Keep gameplay RNG separate from cosmetic randomness; rewind includes RNG state. Daily boards and pending scores expire after three days. Local daily rewards and yesterday's top-ten claim are once per date.
- Stats: `api/stats.js` counts visits/plays only after explicit usage-count opt-in, first-party and cookie-free. No raw IPs, skips bots and Do Not Track / GPC. Owner page `web/stats.html` needs env `STATS_KEY`; never print it. Preview Redis keys are branch-prefixed; never use production boards for tests.
- Settings: `web/settings.js` persists only to localStorage. All sound uses the engine's master gain; preserve first-gesture Safari unlock. Respect reduced motion and draw distinct colour-blind symbols in Match/Prism. Sky Hop, Sky Striker and Pulse Breaker have portrait layouts (selected from stats).
- 3D: source for RAMPAGE is `web/games3d/rampage.js`; `tools/build_rampage.py` reuses ECHO 3D's licensed inline THREE bundle. Both games must work offline, with touch joystick, pause, rewind, rewards and shared settings.
- Generate in order: `python tools/build_rampage.py`, `python tools/make_legal.py` when copy changes, `python tools/build_previews.py`, `python web/build_dist.py`. Commit generated HTML/PNG/dist and bump `web/sw.js` CACHE. Social pages contain the launcher plus per-game metadata; unknown routes show the grid.
- Validate with `npm test` and `npm run test:browser` (set `WEBKIT=1` for WebKit). Cover desktop 1280, portrait 390×844, landscape 844×390, web/dist, privacy, tokens, seed parity, deep links and touch controls. Document actual browser limitations; do not claim physical-device tests from emulation.
- Legal pages (terms, privacy, guidelines, delete) are generated by `tools/make_legal.py` in Breekit's plain-language format. Edit the copy there, bump VERSION/UPDATED, re-run. Keep them true to what the code does.
- Keep MIT licensing and third-party license notices. Never commit secrets.
- Use feature branches and PRs for future changes; do not merge without owner approval.
- Verify the grid and both 2D and 3D games at phone and desktop widths before shipping UI changes.
